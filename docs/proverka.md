# Что проверить до занятий

См. также полный список в [materialy.md](materialy.md).

## Резисторы

Синие в комплекте, скорее всего, **10 кОм**. Для светодиодов нужны **220–330 Ом**. Проверь мультиметром или по полосам и подпиши пакеты.

## Индикаторы

Определи полярность (общий анод или катод) у:

- 1-разрядного 7-сегментного;
- 4-разрядного 7-сегментного;
- матрицы 8×8 (1088BS).

## Зуммеры

Подпиши, какой **активный** (TNB12A05 / TMB12A05), а какой **пассивный**: для `tone()` нужен пассивный. Немаркированный проверить подачей 5 В напрямую: пищит постоянно — активный.

## Пайка

Гребёнки **LCD** и **RC522** надо паять — лучше вместе с учеником под присмотром.

## Осторожно

- **RC522** — только на **3,3 В**.
- К **реле** никогда не подключаем 220 В; у нас оно только щёлкает.
- **Датчик воды** держим подальше от платы.
- **Серво** и **шаговый** от USB могут перезагружать плату — при глюках думай про отдельное питание.

## Библиотеки Arduino

Понадобятся (ставить через Library Manager):

| Библиотека | Для чего |
|------------|----------|
| IRremote | ИК-пульт |
| Keypad | клавиатура 4×4 |
| LiquidCrystal_I2C | LCD по I2C |
| DHT | DHT11 |
| MFRC522 | RFID RC522 |
| библиотека для DS1302 | RTC (чип уточнить) |

Встроены: **Servo**, **Stepper**.
