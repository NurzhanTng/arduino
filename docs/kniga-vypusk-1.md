# Книжка: выпуск 1

Первый выпуск серии. По дорожной карте это переход к [фазе 1](roadmap.md) (решения: if/else, кнопка). Уроки 3 и 4 в книжке как раз эта фаза.

Сборка: `python build.py` → `arduino_uroki.pdf` (см. [README docs](README.md)).

## Модули кода

| Файл | Роль |
|------|------|
| `lib.py` | шрифты, цвета, блоки кода, рамки «Запомни»/«Осторожно», таблицы, шапка и номера страниц |
| `diagrams.py` | схемы, коробки-переменные, блок-схемы if/else, монитор порта, кнопка изнутри |
| `build.py` | обложка, вступительные страницы, начало урока 1; в конце `exec` для `p2`–`p5` |
| `p2.py` | остальные страницы урока 1 (переменные) |
| `p3.py` | урок 2 (типы данных) |
| `p4.py` | **нет файла** — зарезервирован под урок 3 (if/else) |
| `p5.py` | пустой stub — урок 4 (кнопка) и финал (шпаргалка, ошибки, ответы) |

Как только появятся `p4.py` / содержательный `p5.py`, `build.py` подхватит их сам:

```python
for f in ('p2.py', 'p3.py', 'p4.py', 'p5.py'):
    if os.path.exists(f):
        exec(open(f, encoding='utf-8').read())
```

В `diagrams.py` уже есть заготовки под if/кнопку (`d_flow2`, `d_flow3`, `d_button_inside`, `d_pullup`, `d_bounce` и др.).

## Что готово

- обложка, начало, повторение;
- **урок 1** — переменные;
- **урок 2** — типы данных (int, float, bool, String).

Сейчас PDF ≈ **22 страницы** (обложка + страницы 2–22 в логе сборки).

## Что ещё не написано

- урок 3 — if/else;
- урок 4 — кнопка;
- шпаргалка;
- типичные ошибки;

## Известный баг вёрстки

Страница **«bool — да или нет»** (`p3.py`) при сборке даёт:

```text
p19 bool — да или нет   ...   <<< OVERFLOW 1
```

Последний рисунок (timeline) не помещается в кадр страницы. Пока не чинили.
