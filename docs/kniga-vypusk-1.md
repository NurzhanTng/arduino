# Книжка: выпуск 1

Фаза 1 дорожной карты ([curriculum.md](curriculum.md)): переменные → типы → if/else → кнопка.

Сборка: `python build.py` → `arduino_uroki.pdf`.

## Модули

| Файл | Роль |
|------|------|
| `lib.py` | вёрстка, закладки, ссылка «← Содержание», `term_link` |
| `diagrams.py` | рисунки |
| `build.py` | обложка, **содержание** (2 прохода), начало; `exec` p2–p5 |
| `p2.py` | урок 1 |
| `p3.py` | урок 2 |
| `p4.py` | урок 3 (if/else) |
| `p5.py` | урок 4 (кнопка) + типичные ошибки + **справочник** |

Brief’ы: [uroki/03-if-else.md](uroki/03-if-else.md), [uroki/04-knopka.md](uroki/04-knopka.md).

## Готово

- обложка, содержание со ссылками, закладки;
- уроки 1–4;
- типичные ошибки;
- справочник команд и терминов (без решений).

## Не входит (намеренно)

Ответы и решения — отдельный PDF позже, когда понадобится.
