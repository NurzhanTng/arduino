# Дорожная карта

Ориентируйся на **вехи**, не на даты. Полная дуга и принципы урока — в [curriculum.md](curriculum.md). Процесс написания — в [process.md](process.md).

## Как разбить комплект

| Группа | Детали |
|--------|--------|
| **База** | светодиоды, RGB-модуль, кнопки, потенциометр, зуммеры |
| **Датчики («глаза»)** | фоторезистор, LM35, DHT11, звук, наклон, вода, джойстик |
| **Вывод информации** | 7-сегментные индикаторы, 74HC595, матрица 8×8, LCD |
| **Движение** | серво, шаговый мотор, реле |
| **Управление и данные** | ИК-пульт, клавиатура 4×4, RFID, часы RTC |

Полный перечень — в [materialy.md](materialy.md).

## Фазы

| Фаза | Программирование | Детали | Веха |
|------|------------------|--------|------|
| **0. Железо** | IDE, плата, загрузка; макетка; LED и резистор | плата, макетка, светодиоды | сам собрал LED по схеме |
| **1. Решения** | if/else, `&&`, `\|\|`, `!`, кнопка, Serial | кнопки, RGB, активный зуммер | сам пишет if; светофор со звуком |
| **2. Повторение** | while, for, массивы, random | LED, RGB, потенциометр | цикл — его инструмент |
| **3. Функции** | функции, параметры, `millis()` | кнопки, зуммер | Саймон / реакция без копипасты |
| **4. Датчики** | `analogRead`, `map`, пороги, библиотека | LDR, LM35, DHT11, звук, наклон, вода | ночник / термометр |
| **5. Показать данные** | биты, `shiftOut`, I2C | 7-seg+595, LCD, RTC | часы / метеостанция |
| **6. Движение и управление** | switch/case, библиотеки | серво, шаговый, ИК, клава, джойстик, RFID | сейф / лампа с пультом |

Тяжёлое в конец: 4-разрядник, матрица 8×8, RFID.

Выпуски PDF: по одному на фазу. [Выпуск 1](kniga-vypusk-1.md) = фаза 1.

## Мост в C++ (не рано)

После уверенных циклов и массивов (фаза 3+): сначала те же простые задачки на Arduino через Serial, потом — в простом C++ онлайн. Не отдельный олимпиадный курс и не замена железу.

Отличия, о которых предупредить позже:

| Arduino (Uno) | Обычный C++ |
|---------------|-------------|
| `int` 16-битный | обычно 32-битный |
| `Serial` | `cin` / `cout` |
| `setup` / `loop` | `main` |
| `String` | `std::string` |

[Wokwi](https://wokwi.com/) — по желанию для тренировки без проводов; все наши детали не проверялись.
