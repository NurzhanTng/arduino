# Дорожная карта

Ориентируйся на **вехи**, а не на даты. При 1–2 занятиях в неделю фаза занимает примерно 3–5 недель.

Связь с книжками: [выпуск 1](kniga-vypusk-1.md) закрывает переход к фазе 1 (решения: if/else, кнопка). Дальше — по одному выпуску на фазу.

## Как разбить комплект

| Группа | Детали |
|--------|--------|
| **База** | светодиоды, RGB-модуль, кнопки, потенциометр, зуммеры |
| **Датчики («глаза»)** | фоторезистор, LM35, DHT11, звук, наклон, вода, джойстик |
| **Вывод информации** | 7-сегментные индикаторы, 74HC595, матрица 8×8, LCD |
| **Движение** | серво, шаговый мотор, реле |
| **Управление и данные** | ИК-пульт, клавиатура 4×4, RFID, часы RTC |

Полный перечень — в [materialy.md](materialy.md).

## Фазы

| Фаза | Программирование | Детали | Итоговый проект |
|------|------------------|--------|-----------------|
| **0. Железо** | IDE, плата, компиляция и загрузка; ряды макетки; светодиод и резистор | плата, макетка, светодиоды | собрать светодиод сам по схеме |
| **1. Решения** | if/else, `&&`, `\|\|`, `!`, кнопка, Serial для отладки | кнопки, RGB, активный зуммер | пешеходный светофор со звуком |
| **2. Повторение** | while, for, массивы, random | 5–10 светодиодов, RGB, потенциометр | бегущий огонь, радуга на RGB |
| **3. Функции** | свои функции, параметры, `millis()` вместо `delay` | кнопки, зуммер | игра «Саймон», игра на реакцию |
| **4. Датчики** | `analogRead`, `map`, пороги, float, первая библиотека | LDR, LM35, DHT11, звук, наклон, вода | ночник, термометр, хлопок-выключатель |
| **5. Показать данные** | массивы шаблонов, биты, `shiftOut`, I2C | 7-сегментный + 595, LCD, RTC | часы или метеостанция на LCD |
| **6. Движение и управление** | switch/case, библиотеки | серво, шаговый, ИК-пульт, клавиатура, джойстик, RFID | сейф с кодом, лампа с пультом |

### Тяжёлое — в конец

- 4-разрядный индикатор (мультиплексирование);
- матрица 8×8 (16 выводов, а регистр сдвига один);
- RFID (3,3 В, пайка).

## Отдельная дорожка: настоящий C++

После циклов и массивов (с фазы 3) — **15–20 минут в неделю без железа**. Задачи простые: сумма 1..n, максимум в массиве, цифры числа, FizzBuzz.

Сначала на Arduino с выводом в Serial, потом перенос на компьютер.

### Отличия, о которых надо предупредить

| Arduino (Uno) | Обычный C++ на компьютере |
|---------------|---------------------------|
| `int` 16-битный (до 32 767) | `int` обычно 32-битный |
| `Serial` | `cin` / `cout` |
| `setup` / `loop` | `main` |
| `String` | `std::string` |

Онлайн-симулятор [Wokwi](https://wokwi.com/) можно пробовать для тренировки без проводов — поддержка всех наших деталей не проверялась.
