# Дорожная карта

Ориентируйся на **вехи**, не на даты. Полная дуга — в [curriculum.md](curriculum.md). Процесс — в [process.md](process.md).

## Как разбить комплект

| Группа | Детали |
|--------|--------|
| **База** | светодиоды, RGB-модуль, кнопки, потенциометр, зуммеры |
| **Датчики («глаза»)** | фоторезистор, LM35, DHT11, звук, наклон, вода, джойстик |
| **Вывод информации** | 7-сегментные индикаторы, 74HC595, матрица 8×8, LCD |
| **Движение** | серво, шаговый мотор, реле |
| **Управление и данные** | ИК-пульт, клавиатура 4×4, RFID, часы RTC |

Полный перечень — в [materialy.md](materialy.md).

## Фазы

| Фаза | Программирование | Детали | Веха |
|------|------------------|--------|------|
| **0. Железо** | IDE, плата, загрузка; макетка; LED | плата, макетка, светодиоды | сам собрал LED |
| **1. Решения** | if/else, `!`, кнопка, Serial | кнопки, 3× LED | проект «пешеходный светофор» без звука; сам пишет if |
| **2. Повторение** | while, for, массивы, random | LED, RGB, потенциометр; затем зуммер | цикл — инструмент; можно добавить звук |
| **3. Функции** | функции, параметры, `millis()` | кнопки, зуммер | Саймон / реакция |
| **4. Датчики** | `analogRead`, `map`, пороги, библиотека | LDR, LM35, DHT11, звук, наклон, вода | ночник / термометр |
| **5. Показать данные** | биты, `shiftOut`, I2C | 7-seg+595, LCD, RTC | часы / метеостанция |
| **6. Движение и управление** | switch/case, библиотеки | серво, шаговый, ИК, клава, джойстик, RFID | сейф / лампа с пультом |

`&&` / `||` — когда понадобятся два условия сразу (часто рядом с датчиками или кнопкой+состоянием), не обязательны для закрытия выпуска 1.

Тяжёлое в конец: 4-разрядник, матрица 8×8, RFID.

Выпуски PDF: по одному на фазу. [Выпуск 1](kniga-vypusk-1.md) = фаза 1. Brief проекта: [uroki/final-peshehod.md](uroki/final-peshehod.md).

## Мост в C++ (не рано)

После уверенных циклов и массивов (фаза 3+): сначала задачки на Arduino через Serial, потом простой C++ онлайн.

| Arduino (Uno) | Обычный C++ |
|---------------|-------------|
| `int` 16-битный | обычно 32-битный |
| `Serial` | `cin` / `cout` |
| `setup` / `loop` | `main` |
| `String` | `std::string` |

[Wokwi](https://wokwi.com/) — по желанию; все наши детали не проверялись.
