## Цель

Переписать пешеходный светофор коротко: мигание жёлтого через `for`, погасить все — через массив пинов. В хвосте — короткий звук при «idi».

## Железо

LED 8/9/10, кнопка пин 2, Serial, зуммер пин 11 (+ → 11, − → GND). Без `millis`, без своих функций.

## Канон фаз

`faza` 0 красный, 1 жёлтый, 2 зелёный.
