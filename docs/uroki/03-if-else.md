# Урок 3 — if / else

Brief до кода в `p4.py`. Решения в brief не пишем.

## Цель

Научиться просить Arduino **принимать решение**: если условие верно — сделать одно, иначе — другое.

## Одна новая вещь

Команды `if` / `else` (на уже знакомых лампах и bool).

## Уже умеет

- переменные и типы (уроки 1–2);
- `pinMode`, `digitalWrite`, `delay`;
- bool, `true` / `false`, `!`.

## Страницы PDF (порядок = сборка)

1. Зачем решения (сравнение со светофором «в голове»).
2. Сравнения: `>`, `<`, `==`, `!=` (с нуля, на числах).
3. Как выглядит `if` — условие в скобках, блок в `{ }`.
4. `else` — «иначе».
5. Ракета: стоп через if.
6. Фаза в коробке (`faza` 0 красный / 1 жёлтый / 2 зелёный) — семя этапа 2 проекта; `d_flow2`.
7. Задания + «сломай».
8. Мини-тест без подсказки.

## Выполнимые задания

1. Напечатать и загрузить пример с `if`: лампа горит только если число в коробке больше порога (порог меняет руками).
2. Добавить `else`: иначе горит другая лампа (пин 9).
3. «Сломай»: заменить `==` на `=` в условии — увидеть странное поведение / ошибку и починить.
4. Мини-задача без подсказки: если `schet` чётный — красный, иначе зелёный (можно через `%` если уже был в уроке 2, иначе через bool-флаг).

Успех: сам объясняет вслух «если … то … иначе …» и программа на плате делает то, что он сказал.

## Сломай специально

В условии написать `pauza = 500` вместо `pauza == 500` (или убрать фигурные скобки у `if` с двумя командами).
