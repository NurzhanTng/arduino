# Урок 7 — массивы

Brief до кода в `p8.py`. Решения не пишем. Выпуск 2.

## Цель

Хранить **несколько значений в одном списке** и проходить по ним циклом — убрать тройки одинаковых `digitalWrite` / `pinMode`.

## Одна новая вещь

Массив (`int pins[] = {…}`) + обход `for`.

## Уже умеет

- `for` / `while`;
- три LED на 8/9/10.

## Страницы PDF (порядок = сборка)

1. Боль: три pinMode / «погасить все» — снова копипаста.
2. Ряд коробок с номерами — массив как коробки, индекс с 0 + `d_array_boxes`.
3. Как объявить и читать — `pins[i]` + `d_array_index`.
4. Как for бежит по ряду — `d_array_walk` (как поток for).
5. Пример: pinMode и погасить все циклом (`d_wiring` 8/9/10).
6. Бегущий огонь / ряд пауз.
7. Задания и «сломай».
8. Мини-тест + справочник.

## Выполнимые задания

1. Массив из трёх пинов; в setup все OUTPUT через for.
2. Бегущий огонь: зажечь pins[i], погасить, i по кругу.
3. «Сломай»: `pins[3]` при длине 3 — понять выход за край (осторожно).
4. Мини-задача: массив пауз `{500, 200, 1000}` — мигать красным с этими паузами по кругу.

Успех: сам пишет «погасить все» одним for по массиву пинов.

## Сломай специально

`pins(0)` вместо `pins[0]`; индекс с 1 вместо 0; выход за край.

## В справочник

массив, индекс, `[]`.

## Связь с проектом модуля

«Погасить все» в пешеходе v2 — через массив пинов.

## Не входит

динамические массивы STL, указатели, RGB (урок 9).
