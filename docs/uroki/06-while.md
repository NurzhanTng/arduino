# Урок 6 — while

Brief до кода в `p7.py`. Решения не пишем. Выпуск 2.

## Цель

Научиться повторять код **пока условие правда** — цикл `while` (не заранее известное N).

## Одна новая вещь

`while` на лампе + кнопке (уже знакомы).

## Уже умеет

- `for` (урок 5);
- `digitalRead`, `INPUT_PULLUP`, if.

## Страницы PDF (порядок = сборка)

1. Чем while отличается от for: «пока…», а не «ровно N раз».
2. Как выглядит while — условие + тело + `d_while_anatomy`.
3. Как крутится while — `d_while_flow`; warn про бесконечный цикл и `;`.
4. Пример: пока кнопка нажата — лампа горит (`d_wiring` пин 2 + пин 8).
5. Ждать отпускания — while, потом мигнуть зелёным.
6. Задания и «сломай».
7. Мини-тест + справочник.

## Выполнимые задания

1. Пока пин 2 = LOW — красный горит; отпустил — гаснет.
2. Через while дождаться отпускания кнопки, потом мигнуть зелёным один раз.
3. «Сломай»: while с условием, которое никогда не станет ложным — увидеть «зависание», починить.
4. Мини-задача: пока держишь кнопку — жёлтый мигает (достаточно HIGH/LOW+delay в while; for внутри — бонус).

Успех: сам выбирает for vs while («знаю сколько раз» vs «пока условие»).

## Сломай специально

`while (true)` без выхода; или условие с `=` вместо `==`; `;` после `while (...)`.

## В справочник

`while`, бесконечный цикл.

## Связь с проектом модуля

Опционально; for важнее для мигания пешехода.

## Не входит

массивы, random, RGB, функции, millis.
