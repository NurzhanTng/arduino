# Урок 8 — random

Brief до кода в `p9.py`. Решения не пишем. Выпуск 2.

## Цель

Получать **случайное число** и использовать его с уже знакомыми for / массивом / if.

## Одна новая вещь

`random` (+ коротко `randomSeed`: «чтобы после включения не одно и то же»).

## Уже умеет

- for, while, массивы, if;
- LED + Serial.

## Страницы PDF (порядок = сборка)

1. Зачем случайность (игра, вспышка «не угадаешь»).
2. Что возвращает `random` — диапазон 0…N−1 + `d_random_range`.
3. Случайная коробка из ряда — `random` + массив + `d_random_pick`.
4. Пример на плате: три лампы + Serial (`d_wiring` 8/9/10).
5. `randomSeed` простыми словами (чтобы после Reset не один сценарий).
6. Задания и «сломай».
7. Мини-тест + справочник.

## Выполнимые задания

1. Каждые ~500 мс зажигать случайную из 8/9/10 на короткое время.
2. Serial печатает выпавшее число — сверить с лампой.
3. «Сломай»: думать, что `random(3)` даёт 1…3 (на самом деле 0…2).
4. Мини-задача: Arduino печатает загаданное 0/1/2 в Serial; угадай, какая лампа загорится.

Успех: объясняет диапазон random и выбирает лампу через ряд + индекс.

## Сломай специально

`random(3)` ≠ 1…3; забытый seed — одинаковая «случайность» после Reset (обсудить).

`random`, `randomSeed`.
