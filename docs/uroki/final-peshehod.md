# Финальный проект модуля: пешеходный светофор

Brief для блока в `p5.py` после урока 4, до типичных ошибок и справочника. Решения не пишем.

## Цель

Собрать из всего выпуска 1 один проект: машины едут по светофору, кнопка — «хочу идти», зелёный пешеходу. В конце кода много повторов — ребёнок сам чувствует, зачем циклы и функции.

## Железо

Только уже знакомое: LED 8/9/10, кнопка пин 2 → GND, Serial. Без зуммера, RGB, `&&`, `millis`.

## Этапы в PDF

| Этап | Содержание |
|------|------------|
| 0 | Задумка: красный ждёт, кнопка = запрос, зелёный = иди |
| 1 | Машины: три лампы по очереди, коробки времени |
| 2 | `faza` + if/else if (канон: 0 красный, 1 жёлтый, 2 зелёный — как в уроке 3) |
| 3 | Кнопка-запрос + Serial `zhdi` / `idi`; машины как в этапе 2, кнопка только вставляет пешехода |
| 4 | Боль: жёлтый мигает 3 раза без цикла (6× digitalWrite+delay) |
| 5 | «Что бесит» → анонс for и функций; тизер реакции/millis |

## Критерий «сделал»

Работает на плате: авто-цикл машин, по кнопке — мигание жёлтого и зелёный пешеходу, в мониторе понятные слова. Ребёнок может показать взрослому без подсказки по тексту этапов.

## Боли (намеренно)

- Три мигания жёлтого копипастой.
- Тройки `digitalWrite` «погасить все» / «зажечь одну».

## Не входит

Звук, две кнопки, `for`, свои функции, `millis`, готовый «правильный» короткий код в ученической книжке.
