# Учебная дуга

Документ для родителя/преподавателя. Сроки не фиксируем — двигаемся по **вехам освоения**.

## Итог пути

В конце ребёнок:

1. **Умеет программировать самостоятельно** — сам пишет и отлаживает логику (условия, циклы, массивы, функции).
2. **Знает базу** — IDE, плата, пины, питание, Serial, библиотеки; позже мягкий мост к обычному C++ (`main`, cin/cout).
3. **Знает все модули комплекта** — у каждой детали из [materialy.md](materialy.md) был осмысленный опыт (карточка + рабочий скетч).
4. **Может затевать большие свои проекты** — сейф, метеостанция, игра — без пошаговой тетради на каждый шаг.

Критерий «тема усвоена»: сам применил в **трёх разных** контекстах; в занятии были «сломай специально» и мини-задача без подсказки. Тогда — дальше.

## Принципы каждого урока

1. **Самостоятельная работа в центре.** Текст — опора; ребёнок собирает, печатает, меняет, решает.
2. **Всё связано.** Одна линия: зачем → идея → пример → повтори → задание.
3. **С нуля.** Новый термин и команда объясняются простыми словами и попадают в справочник в конце PDF.
4. **Задания обязательны и выполнимы** на уже пройденном материале и железе из комплекта.

Решения в ученический PDF **не кладём**. Отдельный PDF с решениями — когда уроки выпуска готовы.

## Фазы = выпуски PDF

| Выпуск | Программирование | Модули | Веха «можно дальше» |
|--------|------------------|--------|---------------------|
| **0** Железо | IDE, макетка, LED | плата, LED | сам собрал LED |
| **1** Решения | if/else, кнопка, Serial | кнопки, RGB, зуммер | сам пишет if; светофор со звуком |
| **2** Повторение | while, for, массивы, random | LED, RGB, потенциометр | цикл — его инструмент |
| **3** Функции | функции, `millis()` | кнопки, зуммер | Саймон / реакция без копипасты |
| **4** Датчики | analogRead, map, библиотека | LDR, LM35, DHT, звук, наклон, вода | ночник / термометр |
| **5** Дисплеи | shiftOut, I2C | 7-seg+595, LCD, RTC | часы / метеостанция |
| **6** Движение | switch/case, библиотеки | серво, шаговый, ИК, клава, джойстик, RFID | сейф / лампа с пультом |

Тяжёлое (4-разрядник, матрица 8×8, RFID) — в хвосте фаз 5–6, но в итоге все модули в опыте.
