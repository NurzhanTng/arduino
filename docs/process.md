# Процесс работы над уроком

Один заход = **один урок**. Не начинаем следующий, пока текущий не собран без OVERFLOW и brief закрыт.

## Шаги

1. **Brief** в `docs/uroki/NN-tema.md` (пока файла нет — код урока не пишем).
2. Страницы в `pN.py` (+ рисунки в `diagrams.py` при необходимости).
3. `python build.py` — смотрим лог `free=` / `OVERFLOW`.
4. Проверка связности и выполнимости заданий.
5. Обновить записи для **справочника** команд/терминов (финал выпуска).
6. СТОП.

## Шаблон brief

- Цель одной фразой.
- **Одна новая вещь** (понятие или деталь).
- Что уже должен уметь.
- Список страниц PDF (заголовки).
- Список **выполнимых** заданий (что собрать / написать / как понять успех).
- «Сломай специально» + мини-задача без подсказки.
- Какие термины/команды добавить в справочник.
- **Без раздела «ответы».**

## Принципы текста урока

См. [curriculum.md](curriculum.md): самостоятельность, связность, объяснения с нуля, выполнимые задания.

## PDF выпуска

- **Содержание** в начале (кликабельное) + закладки + ссылка из футера.
- Уроки.
- Типичные ошибки (по желанию).
- **Справочник** команд и терминов в конце (со ссылками).
- Решения — **отдельный PDF позже**, не в этой книжке.

## Модули кода

| Файл | Роль |
|------|------|
| `build.py` | выпуск 1: обложка, содержание, начало; `exec` p2–p5 |
| `p2.py`…`p5.py` | выпуск 1 |
| `build2.py` | выпуск 2: обложка, содержание, начало; `exec` p6… |
| `p6.py`… | выпуск 2 (по brief’ам) |
| `lib.py` / `diagrams.py` | общее |

Старые уроки не переписываем «заодно», кроме явного бага (например OVERFLOW).
Один выпуск = один PDF. Brief выпуска 2 — [kniga-vypusk-2.md](kniga-vypusk-2.md).
