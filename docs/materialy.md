# Список материалов

Текущий комплект: **35 пунктов**. Многое опознано по фото и маркировке — то, что не подтверждено, отмечено в тексте.

## Под вопросом (проверить в первую очередь)

- резисторы: по фото похожи на **10 кОм**, для светодиодов нужны **220–330 Ом**;
- полярность 7-сегментных и матрицы 8×8;
- какой из двух зуммеров пассивный (для `tone()`);
- номинал потенциометра;
- активный уровень релейного модуля;
- чип RTC (вероятно DS1302), батарейка;
- DHT11 vs DHT22 (синий корпус — скорее DHT11).

Подробный чеклист — в [proverka.md](proverka.md).
